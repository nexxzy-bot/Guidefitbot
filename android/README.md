# GuideFit — Android-обёртка для RuStore

WebView-обёртка приложения (без Gradle — сборка через aapt/javac/d8/apksigner).

## Требования

- JDK 17 (`sudo apt install openjdk-17-jdk-headless`)
- Android SDK: `$ANDROID_HOME/platforms/android-35` и `$ANDROID_HOME/build-tools/35.0.0`
  (устанавливаются через `cmdline-tools/bin/sdkmanager "platforms;android-35" "build-tools;35.0.0"`)

## Сборка

```bash
node scripts/gen-icons.js           # пересобрать иконки (после правки scripts/gen-icons.js)
bash android/build.sh               # версия берётся из package.json
bash android/build.sh 2.3.1 231     # явные versionName и versionCode
```

Результат: `android/GuideFit-v<версия>.apk` — подписанный release-APK.

### Ключ подписи

При первой сборке создаётся `android/guidefit-release.keystore` (пароль по умолчанию
`guidefit2026`, меняется переменной `GUIDEFIT_KS_PASS`). **Обязательно сохрани keystore
в надёжном месте** — без него RuStore не примет обновления приложения (подпись должна
совпадать между версиями). Ключ не коммитится в git (см. `.gitignore`).

## Манифест и версии

- `versionName` синхронизирован с `package.json` (сейчас 2.3.1)
- `versionCode` считается из версии: major*100 + minor*10 + patch (2.3.1 → 231)
- при каждой публикации в RuStore повышай versionCode
- `targetSdk 35` (актуальное требование магазина для новых версий), `minSdk 24`

## Что внутри

- `MainActivity` — WebView с localStorage, cookies первого пользователя, только HTTPS
  (`network_security_config`), запрет смешанного контента, Safe Browsing.
- Внутри WebView остаются: домен приложения и VK/OK-домены (вход VK ID).
  Остальные ссылки открываются в браузере.
- Кнопка «Назад» работает внутри истории WebView.
- **Уведомление об обновлении (требование RuStore):** проверка `GET /api/app-version`
  раз в 6 часов; при новой версии — диалог «Обновить в RuStore». Принудительное
  обновление включается в `.env` сервера: `MIN_VERSION=x.y.z`, `FORCE_UPDATE=1`.
- Иконки — все плотности (48–192px) **с полностью залитым фоном** (без прозрачности —
  требование RuStore), генерируются `scripts/gen-icons.js` из SVG.
- `android/ic-store-512.png` — иконка 512×512 для карточки приложения в консоли RuStore.

8. После модерации RuStore может запросить видеоролик работы приложения.

## Известные ограничения WebView-обёртки

- Push-уведомления: реализованы как локальные напоминания (≤2 в день) в вебе и
  уведомления в Telegram-боте; нативный пуш (FCM/RuStore Push) не подключён.
- Сессия хранится в localStorage WebView — при очистке данных приложения потребуется
  повторный вход (для VK-аккаунтов — вход в один тап).
